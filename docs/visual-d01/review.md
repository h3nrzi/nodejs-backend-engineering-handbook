## Reproduction and actual checks

Use the repository root with the existing locked dependencies and installed Chrome/Chromium. The renderer uses the existing browser sandbox; no install is required in this workspace. Set `PUPPETEER_EXECUTABLE_PATH` to an existing browser when needed.

```sh
node docs/visual-d01/replay.mjs --record
node docs/visual-d01/verify.mjs --render --record
```

The first command extracts six **unchanged** TypeScript teaching snippets into disposable files, adds bounded assertions and runs them using Node v24’s `--experimental-transform-types`. This flag transforms the existing parameter-property syntax, emits an experimental warning and performs no type checking. The first strip-only attempt failed on RingQueue’s parameter property; no lesson code was edited to bypass that limitation. [Node v24 TypeScript contract](https://nodejs.org/docs/latest-v24.x/api/typescript.html).

The second command calls the existing `visuals:smoke`, styled self-test, `visuals:check` on all 14 lesson paths and all 13 sources, and `visuals:render` for each SVG. It checks preservation/scope, XML/ARIA, unsafe content, real text bounds, scaled text size, conservative contrast and parsed Markdown image count/loading at both widths. It writes OS-temporary HTML and screenshots. Omit `--render` to inspect committed SVGs, and omit `--record` to preserve versioned evidence. Direct one-asset rendering remains `npm run visuals:render -- -i <source.mmd> -o <output.svg>` using paths in the inventory.

Final command outcomes and per-figure measurements are recorded in the linked evidence; final visual inspection results are below. No D01 application or comprehensive chapter-execution suite exists.
