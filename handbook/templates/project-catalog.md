# Domain project catalog

Domain: DXX
Status: not_started

For each *candidate* include: title, product problem, target users, major product behavior, distinctive engineering challenge (without solution), learning coverage, reason it merits its own project, overlap with others, proposed educational Project Charter path, review status. Do not assume all candidates will be built.

Use [the Charter template](project-charter.md) after concept review. Charters establish educational direction and initial scope, not a Final PRD or implementation architecture. Product Discovery, Final PRD and Module Plan belong to the separately selected implementation repository under [Workflow V2](../docs/workflow.md).
